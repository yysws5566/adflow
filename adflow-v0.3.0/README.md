# AdFlow — 信息流广告 AI 自动混剪系统

自动剪辑信息流广告素材的桌面工具：导入素材 → AI 生成多版文案 → 自动配音、配镜头、上字幕、卡点出片，一次产出多条竖屏变体供投放测试。

对标抖音等竖屏信息流（1080×1920），核心目标是「跑量素材」：钩子前置、2-3 秒一镜头、字幕大而清楚、响度统一 -14 LUFS、每条变体自动防判重。

## 功能

- **素材库管理**：导入视频自动打标（镜头切片 / 质量 / 场景），重复使用自动冷却
- **AI 文案**：输入产品信息，生成 N 版不同人群/场景/钩子的口播脚本（每版可裂变）
- **自动配音**：微软 Edge（免费）/ 阿里 CosyVoice / 火山引擎 / MiniMax，多音色轮换
- **自动剪辑**：镜头 2-3 秒一切、BGM 卡点混排、钩子段自动挑最冲击画面、横屏素材智能转竖屏
- **字幕**：自动断句对齐配音时间戳、前 3 秒钩子放大、关键词高亮、底部安全区防裁切
- **变体工厂**：一套脚本 → 多条成片（镜头顺序/BGM/文案风格/调色微调），批量出片
- **配音裂变**：上传爆款视频/音频 + 自己的文案，按原片语音节奏出同款
- **合规辅助**：广告法敏感词检查、平台屏蔽词管理（生成文案自动过检，违规打回重写）
- **渲染自检**：黑帧 / 分辨率 / 时长 / 爆音 / 响度自动检查，不过关自动标记

## 环境要求

- Python 3.10+（3.12 已验证）
- FFmpeg（剪辑必需）
- Windows / macOS / Linux（界面为 PyQt6）

## 快速开始

```bash
git clone <你的仓库地址>
cd adflow
pip install -r requirements.txt
python main.py
```

### 安装 FFmpeg（必需）

| 系统 | 方法 |
|------|------|
| Windows | `winget install ffmpeg`，或从 ffmpeg.org 下载后把 bin 目录加入 PATH，或解压到项目根的 `ffmpeg\` 目录 |
| macOS | `brew install ffmpeg` |
| Linux | `sudo apt install ffmpeg` |

### 配置 API（三种方式，任选）

1. **界面配置（推荐）**：启动后进「设置 → 🔌 API/模型」，选平台、填 Key、保存。软件内置各平台取 Key 的小白教程
2. **环境变量**：复制 `.env.example` 为 `.env`，填入你的 Key
3. **配置文件**：改 `config.yaml`（可换模型、加自定义 OpenAI 兼容接口）

**AI 文案平台**（选一个）：

| 平台 | 环境变量 | 说明 |
|------|----------|------|
| 阿里百炼 Qwen（推荐） | `DASHSCOPE_API_KEY` | 注册送免费额度 |
| DeepSeek | `DEEPSEEK_API_KEY` | 便宜 |
| Moonshot | `MOONSHOT_API_KEY` | |
| OpenAI 兼容 | `OPENAI_API_KEY` | 自定义中转/接口改 `config.yaml` 的 `llm.providers.openai` |
| 本地 Ollama | 无需 Key | 免费，需本机装 Ollama |

**配音平台**：微软 Edge 免费（无需 Key）；CosyVoice/火山/MiniMax 各需对应 Key（详见软件内教程页）。

没有 API Key 也能用：选本地 Ollama 出文案 + Edge 出配音，全程零费用。

## 使用流程

1. 素材页导入视频素材
2. 项目页填产品信息 → 生成文案 → 人工审核改稿
3. 出片（选竖屏/横屏）→ 成片在 `output/`，每条附 SRT 字幕和剪辑决策 EDL
4. 裂变页：拿爆款参考视频 + 新文案，出同款节奏的新片

## 合规与法律

- **素材必须自有或已获授权**。本工具不提供任何视频/音乐素材，也不抓取平台内容
- 生成内容发布前请人工审核，确保符合《广告法》及投放平台规则；内置敏感词检查只是辅助，不能替代人工把关

## 目录结构

```
adflow/
  agents/        # AI Agent：策略发散、文案生成、素材匹配
  engine/        # 剪辑引擎：镜头、字幕、配音、调色、防判重、变体
  analytics/     # 爆款拆解与审美评分
  compliance/    # 广告法检查、敏感词库
  gui/           # PyQt6 界面
  db/            # SQLite 素材/项目库
main.py          # 入口
config.yaml      # 全局配置（模型/字幕/调色/画幅…）
.env             # 你的密钥（不进仓库）
```

## 常见问题

- **启动提示 FFmpeg 未找到**：按上文安装，或放到项目根 `ffmpeg\bin\`
- **AI 未配置**：不影响素材管理和人工改稿，出 AI 文案/配音时才需要
- **中文字幕乱码/缺字**：设置页「字幕」选一个系统字体（如微软雅黑 msyh.ttc）
- **出片慢**：首次运行会下载 CLIP 语义匹配模型；不想装 torch/transformers 可跳过，混排自动退化为规则排序
